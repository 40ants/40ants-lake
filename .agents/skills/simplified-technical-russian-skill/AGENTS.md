# AGENTS.md

Файл для агентов, которые читают `AGENTS.md`: Codex CLI, Cursor, Cline, Aider,
Continue и другие.

## Правило

Весь русский текст пишите по правилам упрощённого технического русского языка
(УТР) из ГОСТ Р 58049—2017, раздел 8.2.

Полные правила: [`SKILL.md`](SKILL.md).

## Минимальный набор

1. Предложение — не длиннее 20 слов (8.2.5.1).
2. Прямой порядок слов: подлежащее, сказуемое, дополнение (8.2.3.4).
3. Действительный залог. Страдательный залог в инструкциях не применяют (8.2.3.13).
4. Причастные и деепричастные обороты не применяют (8.2.3.11).
5. Один термин — одно понятие во всём тексте. Синонимы запрещены (8.2.3.7).
6. Метафоры, сравнения, сленг и жаргон запрещены (8.2.3.5).
7. Иностранное слово не применяют, если есть равнозначное русское (8.2.3.6).
8. Инструкция: глагол первым, повелительное наклонение множественного числа.
   Единственное число запрещено (8.2.3.9).
9. Одно предложение — одна команда (8.2.5.2).
10. Перечисление — вертикальный маркированный список (8.2.3.16).

Точность важнее краткости. Условие, число и предупреждение не сокращают (8.2.3.15).

## Форма глагола

| Артефакт | Форма | Пример |
|---|---|---|
| Комментарий, docstring | 3-е лицо единственного числа | `Возвращает список заказов.` |
| Причина решения | Неопределённо-личная конструкция | `Индекс не применяют: планировщик выбирает seq scan.` |
| Инструкция, README | Повелительное наклонение множественного числа | `Запустите миграции.` |
| Сообщение об ошибке | Условие, затем команда | `Файл config.yaml не найден. Создайте файл.` |
| Описание коммита | Инфинитив | `Добавить кэш ответов профиля.` |

Идентификаторы, пути, команды и вывод программы не переводят и не склоняют.
