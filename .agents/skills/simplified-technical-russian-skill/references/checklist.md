# Чек-лист проверки текста на УТР

Порядок проверки — от смысла к форме. Пункты приведены по ГОСТ Р 58049—2017.

## А. Смысл и полнота (проверяют первыми)

- [ ] Текст передаёт смысл источника полностью (8.2.4.1).
- [ ] В тексте нет смысловых единиц, которых не было в источнике (8.2.4.1).
- [ ] Ни одно условие, ограничение, число и предупреждение не потеряно (8.2.3.15).
- [ ] Многозначные слова заменены на контекстно точные (8.2.4.5).
- [ ] Каждая смысловая единица понимается однозначно (8.2.3.2).

## Б. Термины

- [ ] Один термин обозначает одно понятие во всём тексте (8.2.3.7).
- [ ] Синонимов для одного понятия нет (8.2.3.7, ГОСТ 2.105).
- [ ] Терминология стандартная или закреплена в глоссарии проекта (8.2.3.7, 8.1.10).
- [ ] Официальные технические термины сокращены, где возможно (8.2.3.8).
- [ ] Сокращение введено при первом употреблении вместе с полной формой (8.2.3.8).
- [ ] Новые термины и сокращения занесены в глоссарий (8.1.7, 8.2.3.8).

## В. Синтаксис

- [ ] Каждое предложение не длиннее 20 слов по правилам подсчёта (8.2.5.1).
- [ ] Порядок слов прямой (8.2.3.4).
- [ ] Подлежащее не стоит в конце предложения (8.2.3.4).
- [ ] Прямое дополнение не стоит перед сказуемым (8.2.3.4).
- [ ] Причастных оборотов нет или их число минимально (8.2.3.11).
- [ ] Деепричастных оборотов нет (8.2.3.11).
- [ ] Составные сказуемые заменены простыми (8.2.3.11).
- [ ] Сложные распространённые предложения разбиты на простые (8.2.3.14).
- [ ] Страдательного залога в инструкциях нет (8.2.3.13).
- [ ] Действительный залог применён везде, где исполнитель известен (8.2.3.3).
- [ ] Трёх и более существительных подряд нет (8.2.3.10).
- [ ] Отглагольные существительные заменены глаголами (8.2.3.10).
- [ ] Лишние предлоги убраны (8.2.3.10).

## Г. Лексика

- [ ] Метафор и сравнений нет (8.2.3.5).
- [ ] Сленга и жаргона нет (8.2.3.5).
- [ ] Иностранных слов при наличии русских эквивалентов нет (8.2.3.6).
- [ ] Опущений и сокращений слов, искажающих смысл, нет (8.2.3.15).
- [ ] Оценочных и неопределённых слов нет: «быстро», «просто», «обычно» (8.2.3.2).

## Д. Инструкции

- [ ] Глаголы стоят в повелительном наклонении множественного числа (8.2.3.9, 8.2.5.3).
- [ ] Повелительного наклонения единственного числа нет (8.2.3.9).
- [ ] Глагол стоит на первом месте в предложении (8.2.3.9).
- [ ] Одно предложение описывает одну команду (8.2.5.2).
- [ ] Две команды в предложении описывают только одновременные действия (8.2.5.2).
- [ ] Описание действий конкретное: названы объекты, значения, пути (8.2.5.4).

## Е. Описательная часть

- [ ] Абзац раскрывает одну тему (8.2.6.2).
- [ ] Абзац содержит не более шести предложений (8.2.6.2).
- [ ] Абзацы из одного предложения встречаются не чаще одного раза на десять абзацев (8.2.6.2).

## Ж. Оформление

- [ ] Перечисления оформляют вертикальными маркированными списками (8.2.3.16).
- [ ] Скобки ставят только по пяти случаям из пункта 8.2.3.17.
- [ ] Слова типа «кнопка» и «ссылка» в пользовательских текстах не применяют (8.2.3.18).
- [ ] Примечание даёт только дополнительную информацию (8.2.3.19).
- [ ] Единицы измерения дают по системе страны назначения, исходные — в скобках (8.2.4.6).

## З. Для кода (адаптация)

- [ ] Идентификаторы, пути и команды не переводят и не склоняют.
- [ ] Комментарий и docstring описывают поведение в 3-м лице настоящего времени.
- [ ] Комментарий о причине решения отвечает на вопрос «почему».
- [ ] Сообщение об ошибке содержит факт, контекст и действие.
- [ ] Описание коммита открывает инфинитив.
- [ ] Один комментарий держит один язык.
- [ ] Кириллических идентификаторов нет.

## Быстрая проверка одного предложения

Семь вопросов. Если ответ «нет» хотя бы на один — правьте.

1. Не длиннее 20 слов?
2. Подлежащее перед сказуемым, дополнение после?
3. Действительный залог?
4. Без причастных и деепричастных оборотов?
5. Термины совпадают с остальным текстом?
6. Без метафор, жаргона и лишних англицизмов?
7. Одна команда, глагол первым, во множественном числе?

## Что проверяет линтер

`scripts/utr_lint.py` покрывает длину предложения и абзаца, частоту однопредложных
абзацев, причастия и деепричастия. Он также проверяет страдательный залог, цепочки
существительных и повелительное наклонение единственного числа. Отдельные правила
ловят лексические запреты, перечисления внутри предложения и число команд.

Линтер не проверяет: полноту смысла, порядок слов, единство терминологии без
глоссария, корректность применения скобок, конкретность описаний. Эти пункты
проверяет модель или человек.
